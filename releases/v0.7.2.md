## Pluto's Terminal v0.7.2

New models show up without an app update. Full detail in `CHANGELOG.md`.

### New
- **The Models picker lists what each provider actually serves.** It used to
  know only the models typed into the app when it was built, so Claude Opus 4.8
  was the newest it offered. Once you set a provider's key, the picker asks
  that provider for its current list, newest first, and anything released in
  the last 30 days carries a "new" label. Claude Opus 5.5, Sonnet 5.5 and
  Fable 5.1 are there today, and whatever comes next will be too.
- **The list stays fresh on its own.** It refreshes when you open a provider's
  row and it is over an hour old, and once per launch in the background, for
  providers reached over https, when it is over 12 hours old. There is a
  Refresh button for right now.
- **A long list gets a filter box**, so OpenRouter's hundreds of models are one
  search away. Models that cannot run an agent (embeddings, speech, image,
  moderation) are left out; you can still type any model id.
- **Your phone's model picker shows the same lists.**

### Safer
- The list request uses the same key and address a new shell would use, only
  over https (plain http only to your own machine or local network), and it
  never follows a redirect to another server.
- A provider's error text is never saved to disk. The app keeps only a short
  summary such as "HTTP 401", and the full message shows for the current
  session only, with your key scrubbed from the forms providers usually echo
  it in.
- If anything in the Models dialog ever fails to draw, you get a message
  instead of the app-wide error screen, which used to close every open
  terminal and SSH session.

### Changed
- The built-in Anthropic list, shown before a key is entered, is current:
  Claude Opus 5.5, Sonnet 5.5, Fable 5.1, Haiku 4.5, Opus 5, Sonnet 5 and
  Opus 4.8.
