# v0.1.14 — polish closeout (Bundle 1 of 6)

Five targeted polish wins. First of six bundles in the "do all of them" plan.

## What's new

### 🎨 Tab strips follow the skin
Tabs at the top of each panel now read skin CSS vars instead of hardcoded dark colors. Tab strip background = surface bg; active tab background = xterm bg (so it visually merges with the terminal output area below); active tab underline = link accent; tab text = surface fg. Active-tab + xterm-output area read as a single continuous surface.

### 📥 Drag-drop visual hint overlay
Drag a `.deck.json` file over the window and a full-window overlay appears: "📥 Drop a prompt pack to load it · `.deck.json` file · replaces current panels". Skin-aware (uses `--phn-link` for the dashed border, `--phn-surface-bg` for the card). Disappears on drop / dragleave. Solves the v0.1.10-flagged invisible-feature problem.

Also: dropping a non-`.deck.json` file now shows a branded toast error instead of silently doing nothing.

### 🎨 Welcome screen reads saved skin
`applyGlobalSkin` + `applyGlobalButtonStyle` moved from TerminalsTab to App.jsx so they fire **before** the Welcome screen renders. Returning users now see the welcome screen in their saved skin, not the default. Welcome screen color constants converted to `var(--phn-...)` references — every welcome surface follows the active skin.

### 🛡 Pre-flight `claude` check
Pack startCommands now check `Get-Command claude` before invoking. If the CLI isn't on PATH, the terminal shows a clear error in-place:

```
[pluto's terminals] Claude CLI not found on PATH.
  Install: npm install -g @anthropic-ai/claude-code
  Or click 🚀 setup in the header for guided steps + live API test.
  Skipping pack startCommands and systemPrompt; shell is yours.
```

…instead of the previous silent garbage where the shell printed `claude is not recognized` and 2s later the systemPrompt got typed into a confused PowerShell. Detection: any startCommand whose first token is `claude`.

### 📦 4 new prompt packs

- **`language-learning.deck.json`** — patient language tutor; drills vocab/grammar/conversation in 15-min sessions with encouraging tone and inline corrections
- **`interview-prep.deck.json`** — mock interviewer; pushes back on vague claims, gives feedback after each answer, ends with pattern summary. Notes pane on the right
- **`content-script-writer.deck.json`** — video/podcast/livestream script writer; works in beats (hook/body/callbacks/close), returns camera-ready prose, matches your voice. Draft pane on the right
- **`rubber-duck.deck.json`** — rubber-duck debugging; asks short clarifying questions, NEVER solves, holds the role even if you ask for a solution

Catalog now: **10 functional + 1 reference = 11 packs**. Updated `prompt-packs/README.md`.
