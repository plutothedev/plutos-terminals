# v0.1.22 — pre-launch polish (4 cleanups)

Second of three pre-launch polish releases. Companion to v0.1.21 (shared user state).

## What changed

### 🧹 Dead button-style code removed

The HEADER BUTTONS picker was removed in v0.1.20 (locked everyone to bracket style). I left some dead reads behind: `getButtonStyleId(st?.headerButtonStyle)` + `applyGlobalButtonStyle(headerButtonStyleId)` were still firing in TerminalsTab even though App.jsx hardcodes `applyGlobalButtonStyle("bracket")`. Harmless but misleading. Removed.

`HEADER_BUTTON_STYLES` array stays in `headerSkins.js` — its CSS rules are still consumed (specifically the `bracket` rule). Unused export but easier than re-deriving the rules later if a future release wants to bring back the picker.

### 🎬 Recording memory cap

`recording.js` now caps at **100,000 events** per recording. Captured output beyond that is dropped (the recording still saves cleanly, just truncated to the cap). The status bar `● rec` indicator flips to **⚠ rec capped — save** with a tooltip explaining what to do.

Why: a long-running session at 100KB/s of output would have grown to hundreds of MB in RAM. 100k events is roughly 10–20 MB depending on chunk size — bounded and forgiving without being intrusive for typical 5–30 minute sessions.

### 🪟 Secondary window close UX

Closing a secondary window now **destroys it** instead of hiding it. Previously, closing the X button hid the window (system-tray pattern) but there was no per-window tray entry to bring it back — a closed secondary window was effectively lost.

New behavior:
- **Main window** (label `main`) → still hides on close (PTYs keep running; tray controls)
- **Secondary windows** (label starts with `win-`) → close normally, free their PTYs cleanly. Re-spawn anytime via `Ctrl+K` → 🪟 Open new window.

The detection key is `window.label()`: any non-`main` window is treated as secondary.

### 📁 Brainstorm preview HTML moved out of releases/

`releases/header-styles-preview.html` (1,200-line HTML mock-up of the layouts/skins design space from v0.1.10) → `design/header-styles-preview.html`. Plus a new `design/README.md` explaining what's in there.

The `releases/` folder is now reserved for actual release notes (`v*.md`) — no orphan design docs. Anyone browsing the repo for the first time gets a tighter mental model.
