## Pluto's Terminal v0.7.1

Voice dictation works now, plus everything an outside code audit of v0.7.0
found. Full detail in `CHANGELOG.md`.

### New
- **Dictation works.** Wispr Flow and other voice tools insert text through the
  Windows accessibility layer, and that text was being silently dropped: it
  reached the app but the terminal engine ignored it. It lands in the shell now.
  Typing and clipboard paste were never affected.
- **The terminal takes focus when you switch to the window**, so a dictation
  tool finds a text field instead of nothing. It never steals focus from the
  assistant box, the session tree, or a dialog.

### Fixed
- Cloud sync can no longer be made to write outside its own folder by a
  repository you do not control, and it no longer follows a redirect to another
  server, which could have handed your access token to it.
- Changing the sync repository actually takes effect. It used to be ignored
  silently, so the app kept syncing to the old one.
- Turning sync off stops it. It used to keep pulling and pushing in the
  background until you restarted.
- Provider keys survive a second window. Rotating a key in one window and then
  saving anything in another used to bring the old key back.
- On Windows, keys are stored one per provider instead of all in a single
  entry, which was capped and silently failed once you had about a dozen keys.
  A failed save now tells you instead of losing the key.
- Startup cleanup can no longer delete terminal history that is being restored.
- Sharing to a gist masks more kinds of key, including Google, Groq, xAI,
  Hugging Face and NVIDIA.
- Agent Mode masks command output before sending it to your AI provider. It was
  possible for an approved command to hand one provider's key to another.

### Under the hood
- 948 frontend tests and 247 backend tests, up from 841 and 232.

**Updating:** if you run v0.6.1 or v0.7.0 the app offers this release on launch
and installs it in place. Older versions have no updater and need one manual
install; verify the download against `SHA256SUMS` first.
