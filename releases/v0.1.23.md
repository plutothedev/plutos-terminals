# v0.1.23 — pack systemPrompt tuning pass

Final pre-launch release before YouTube video recording. Tightens the systemPrompts on the 4 packs added in v0.1.14 — language-learning, interview-prep, content-script-writer, rubber-duck.

## What changed

The 4 packs shipped in v0.1.14 with reasonable systemPrompts but no real-Claude testing. This pass tightens each based on prompt-engineering best practices and how Claude actually behaves on first-pass:

### `language-learning.deck.json`

Added: "Go straight to your first question — don't introduce yourself or explain the format first." Anchors the opening to a 3-question intake. Adds: "Use the target language for prompts and examples; switch to English only for grammar explanations and only when the user is beginner." Tightens praise: "never say 'great job!' or 'amazing!' — say specifically what they got right." Anchors session length: "Aim for 5–7 exchanges per round so the user actually completes a session."

### `interview-prep.deck.json`

Same "go straight to first question" frame. Anchors the opening to 3-question intake. **Strong addition:** "Stay neutral mid-loop — real interviewers don't say 'great answer' or 'good point' between questions. Save commentary for the feedback moment." This was the biggest miss in the original prompt — Claude defaults to validation behavior that breaks the interviewer character. Adds an example for the end-of-session pattern summary: "you gave 4 STAR-format answers but only 1 had a quantified result; tighten that."

### `content-script-writer.deck.json`

Same opening frame. Tightens hook-pitch format: "numbered list with 1-line rationale each" instead of vague "pitch 2-3." Adds default cadence anchors for YouTube long-form ("hook in first 8 seconds, value-promise in first 30, first beat at 1:30") so Claude has a target structure when no other guidance exists. Voice-matching clearer: "if they paste a transcript or sample, learn that voice and match it; if they describe it ('casual', 'edgy', 'professional'), calibrate."

### `rubber-duck.deck.json`

Tightest rewrite of the four. Opens with literal scripted line: "Open with: 'What are you stuck on?' Nothing else." Defines "load-bearing assumption" explicitly: "the assumption that, if wrong, would change everything." Adds active-listening behavior: "If the user gives a long monologue, summarize back in one sentence ('so you're saying X?') and ask the next question — show you're tracking." Adds explicit anti-pattern: "Never ask 'and how does that make you feel?' — you're not a therapist." Strengthens the realization handling: "When they say 'wait, that's it' or 'oh' or 'I see', stop and let them explain — don't interrupt the realization."

## Why these prompts now

Pluto wants the YouTube launch demo to land. The packs are the headline feature — the demo of "specialized agents" only works if each pack actually holds its role under casual prompts. v0.1.23 tightens the four packs most likely to be demo'd in the video.
