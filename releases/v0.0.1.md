# v0.0.1 — first scaffold

The first downloadable cut of **Pluto's Terminals**. It works, but it's a v0 — most of the v1 differentiators (in-app prompt-pack browser, agent grid, MCP installer) are still ahead. Today is the multi-terminal foundation, Pluto-branded, free, MIT-licensed.

## What's in this release

- **`Pluto's Terminals_0.0.1_x64_en-US.msi`** — Windows installer (3.0 MB)
- **`plutos-terminals.exe`** — standalone binary, run-without-install (8.9 MB)

## Install (Windows)

Download the MSI → double-click → Windows Installer walks you through. Or download the `.exe` and run it directly without installing.

> **SmartScreen warning:** the installer is unsigned (no code-signing cert yet). Windows will warn — click "More info" → "Run anyway." Code-signing is on the post-v0 list.

## What you get

- Multi-panel terminal grid (foundation lifted from the Lyfe codebase)
- xterm.js 5.5 + portable-pty backend — real PowerShell sessions in each tab
- System tray + hide-on-close — sessions keep running in the background
- Project sidebar — pin folders, set start commands, drag into panels
- Pluto Dark / Pluto Light themes
- Sample `.deck.json` prompt-pack schema (manual load only in v0)

## Not in v0 (planned for v1)

- In-app prompt-pack browser + click-to-load
- Agent grid panel (multi-agent orchestration)
- One-click Anthropic API key + MCP installer
- Linux + macOS installers (Mac/Linux users can build from source: `npm install && npm run tauri build`)
- Code-signed installers

## Stack

Tauri 2.10 + React 18 + Vite 8 + xterm.js 5.5 + portable-pty 0.8 + Rust 2021.
