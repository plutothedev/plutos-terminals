# v0.1.17 — bundle 4: session restore confirmation + reset workspace command

Smaller bundle than initially scoped — turns out most of "snapshot/restore" was already shipping silently:

- **localStorage** persists the full panel/tab layout + cwd + startCommands + systemPrompt + skin/buttons/density on every save
- **Scrollback** persists to disk on tab unmount (`data/terminals/scrollback/<tab_id>.txt`, last ~500 lines / 200KB)
- **Scrollback replay** runs on tab mount with a `─── scrollback restored ───` separator
- **PTY respawn** uses each tab's saved cwd + startCommands + systemPrompt — claude pack tabs reboot Claude with the same role on restart

So restoring a session = open the app. v0.1.17 just makes it visible and adds an opt-out.

## What's new

### 🔄 Session-restore confirmation toast

On app launch, if there's a non-trivial saved layout to restore (more than the default single empty panel), a one-shot info toast appears: **"Session restored — N panels · M tabs"**.

The toast only fires once per launch (not on React remounts) via a ref-guarded effect. First-ever launch (default empty layout) doesn't toast.

### ♻️ "Reset workspace" command

New entry in the `Ctrl+K` command palette: **♻️ Reset workspace** — closes every panel and tab, returns to a single empty panel. Keeps API key, skin, button style, density, projects, and recent packs. Branded confirm dialog before the action runs (it's destructive — kills every PTY).

Useful when you want a clean slate without losing your settings or going through factory reset.

### Note: scrollback continuity

When tabs respawn after restart, the scrollback file replays first (cosmetic), then the new PTY spawns fresh and runs your pack's `startCommands`. Claude Code session itself does NOT resume (Claude CLI doesn't expose session-resume yet). So:

- ✅ Same panels, same tabs, same cwd, same agents
- ✅ Visual continuity (scrollback replay)
- ❌ Same chat history (new Claude session each time — by design until Claude CLI supports `--resume`)

If you want chat continuity, save your session manually before quitting (paste the conversation into Claude when it reboots).
