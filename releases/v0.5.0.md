# Pluto's Terminal v0.5.0 — Security hardening + reliability pass (Windows)

The remote-sessions-parity release, hardened. This bundles the full
SSH/SFTP/RDP/VNC/tunnels, phone companion, cloud sync, native agent + MCP, and
prompt-editor (beta) work with a multi-subsystem adversarial security audit and
a production-readiness pass.

## Security
A full audit across state persistence, remote transports, MCP, and the companion
server found **no critical or exploitable-high** issues. The defense-in-depth
tail was closed: IPv6 private-range classification in the LLM proxy, atomic
MCP-config writes with a serialized add/remove cycle, an RDP known-hosts TOCTOU
lock (plus lock-poison recovery), worktree-command guards, and a masked in-app
access-token prompt replacing a cleartext native prompt.

## Fixed
- **Quit** no longer crashes the UI — it confirms and exits correctly.
- **SFTP New-folder / Rename** now use branded in-app modals instead of the
  native OS prompt.
- Agent-mode capture fails fast when its tab closes mid-command (was ~120s hang).
- The AI error explainer can't be overwritten by a slow stale response.
- Macro recording is memory-capped; three lost-update save races closed.

## Added
- Accessible modals (role=dialog, aria-modal, focus trap, focus restore).
- 14 new regression tests.

## Changed
- In-app copy is now "source-available" (matches the license). The lock screen
  follows the active skin.

## Install
Windows: download the `.msi`, verify its SHA-256 against `SHA256SUMS`, then
install. Builds are not yet code-signed — SmartScreen may warn on first launch
("More info → Run anyway"). See the README Install section for macOS Gatekeeper
steps.
