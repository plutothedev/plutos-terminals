## Pluto's Terminal v0.4.0 — Refined look + stability overhaul

The biggest under-the-hood release yet: a full visual refresh plus a deep
stability pass driven by a whole-codebase audit.

### New look
- **Refined dark theme** — single accent, hairline borders, pill tabs, clean
  monochrome icons. The whole app reads as one surface instead of a patchwork.
- Custom themes (Warp YAML import) still work and now sit on consistent tokens.

### Feels faster, because it is
- **No more UI freezes.** 29 blocking operations (SSH connect, SFTP transfers,
  RDP/VNC connect, network tools…) moved off the UI thread — a slow host can no
  longer hang the window.
- The 2.5s system-stats poll and live cost telemetry no longer re-render the
  entire app.

### Fixed
- Spawned shells reliably receive your provider API keys again (keychain
  migration edge case).
- No more `�` characters in terminal output or saved scrollback (UTF-8 chunk
  boundaries).
- SSH passwords survive duplicating/reopening a tab; no zombie shell processes
  after closing tabs; layout file writes are crash-safe.
- RDP now pins server certificates on first use (like SSH known-hosts); VNC
  validates the handshake and can't hang forever.
- Factory reset actually wipes everything; phone-companion server hardened and
  cleans up Tailscale serve + push subscriptions on stop.
- Dozens more correctness fixes from the audit (`docs/full-audit-2026-06-09.md`)
  and the v0.3.6 security pass.

### Downloads
- **`Pluto's Terminal_0.4.0_x64_en-US.msi`** — recommended Windows installer.
- **`Plutos-Terminal_0.4.0_x64-portable.exe`** — portable single-exe, no install
  (needs the WebView2 runtime, which Windows 11 ships).
- macOS `.dmg` / Linux `.AppImage`+`.deb` attach automatically when the CI build
  for the tag completes.

Builds are unsigned → SmartScreen may warn: **More info → Run anyway**. The MSI
upgrades a prior install cleanly.
