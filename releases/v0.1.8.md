# v0.1.8 — Tier 1: real specialization, real MCP install, URL pack import

The three features that turn prompt packs from "tabs with labels" into the actual differentiator. Closes the loop on what the agent grid was pretending to be.

## Headline features

### 1. `systemPrompt` field — packs as specialized agents

Tabs in a `.deck.json` pack now support a `systemPrompt` string. After the tab's start commands launch `claude` (or any interactive REPL), the app waits 2 seconds for Claude to boot, then types the system prompt as the first user message. Real role specialization.

Bundled v0.1.8 packs all use it:

- **`claude-code-basic`** — concise, file-path-citing assistant
- **`dual-claude-pair`** — code pane focuses on hands-on edits + defers planning to plan pane; plan pane focuses on architecture + tradeoffs + defers implementation
- **`trading-workflow`** — analysis pane primed with ICT methodology (FVG, OB, Power of Three, Killzones, OTE, etc.)
- **`pluto-personal-strategist`** — Strategist Claude reads vault meta files (CLAUDE.md / hot.md / GOALS.md / patterns.md) on first request

Schema doc updated at `prompt-packs/SCHEMA.md`. Author your own with `"systemPrompt": "..."` per tab.

### 2. MCP real auto-install

`🔌 MCPs` modal got an `install` button next to `copy`. Click → app runs `claude mcp add ...` in a hidden shell → toast reports success or error. No more copy-paste ceremony.

Backend: new `mcp_install` Tauri command in `commands.rs` that runs `cmd /c <command>` with safety guards (rejects shell-metacharacters, only allows `claude ...` invocations).

Filesystem MCP's `${PWD}` placeholder gets substituted with `%USERPROFILE%` (your home dir) before install — adjust scope by editing manually if needed.

### 3. Pack import from URL

New `🔗 from URL` button in the header opens a paste-URL modal. Paste a `.deck.json` URL (raw GitHub, gist, any HTTPS host that allows CORS) → app fetches + validates + loads. Closes the share loop:

> Configure your setup → `💾 export` → upload to gist → share URL → anyone clicks `🔗 from URL`, pastes, loads in 2 seconds.

CORS-blocked hosts surface a clear error toast suggesting `📁 from file` after manual download.
