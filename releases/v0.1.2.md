# v0.1.2 — flawless polish pass + agent view toggle

The "make it flawless" pass. v0.1.1 already shipped the plug-and-play surface; v0.1.2 layers on the polish that turns a working app into a pleasant one.

## Headline feature

- **`💻 TERMINAL` ↔ `🤖 AGENT` view toggle** in the header. Agent view renders every open tab across all panels as a compact card — label, project, activity dot (idle / active / done), per-tab cost. Click a card → flip back to terminal view focused on that tab. PTYs stay alive across toggles, so monitoring doesn't kill your sessions.

## Polish

- **Branded toast notifications** (`success / error / info`) replace `window.alert` everywhere. Top-right slide-in, click-to-dismiss, auto-fade after 4s.
- **Branded confirm modals** replace `window.confirm`. Destructive actions (factory reset, agent grid spawn, clear API key) get magenta-accented buttons; non-destructive get the default blue.
- **Status bar** at the bottom of terminal view: version, Claude availability indicator (✓ green / ✗ magenta with click-to-setup), current theme, total live cost across all sessions, repo + Discord links.
- **API key format validation** in ⚙️ settings — flags non-`sk-ant-` keys before saving.
- **README hero** — badges (release / downloads / license / Discord), tagline, feature list rewritten with the new surfaces.
- **CONTRIBUTING.md** + **GitHub issue templates** (`bug-report` / `feature-request` / `pack-submission`) — community-readiness signals.
