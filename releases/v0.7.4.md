## Pluto's Terminal v0.7.4

Copy works on Windows, and agents tell you when they need you. Full detail in `CHANGELOG.md`.

### Fixed
- **Copy works on Windows.** Highlight text and press Ctrl+C to copy it. With
  nothing highlighted, Ctrl+C still stops the running program. Until now
  Ctrl+C never copied, so pressing it to copy out of a Claude Code session
  interrupted Claude instead. Right-click copies when text is highlighted and
  pastes when it is not (it used to paste every time). Ctrl+Shift+C and
  Ctrl+Shift+V copy and paste on every platform.
- **Under broadcast typing, a program's query could type into other panes.**
  The terminal's own answers to a program, and mouse reports, now go only to
  their own pane.

### New
- **Agents report their own status.** Claude Code 2.1.295 and later tells the
  terminal whether it is working, waiting on you, done or failed, and why. The
  Fleet panel, the Monitor, tab dots, panel borders and the home screen show
  "needs you" in the agent's own words.
- **"Needs you" reaches you** as a desktop notification (now on Windows too),
  and as a phone push if the companion has notifications on.
- **Claude Code conversations come back after a restart** in panes that start
  `claude` from a saved session's start commands.
- **Hand a session summary to another agent.** "Summarize session" can paste
  the summary into another agent's pane as a prepared prompt, secrets masked,
  sent only when you press Enter.

### Safer
- **A crafted notification title could run commands on macOS.** Fixed.
- **Settings sync refuses a plain `http://` address outside your own network**
  before it sends any credentials.
- **Phone push notifications go only to the browsers' push services.**
- **AI replies are bounded:** error bodies at 64 KB and 10 seconds, streaming
  replies at 4 MB, so a broken or hostile endpoint cannot exhaust memory.
- rustls 0.23.46 and quinn-proto 0.11.19 clear nine recent advisories.
