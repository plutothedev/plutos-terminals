## Discord post (Pluto Discord — `#announcements` or wherever your launches go)

**Title:** `Pluto's Terminals v0.1.0 — free, MIT, multi-terminal app`

**Body:**

Built this for the community. Free, MIT, downloadable from GitHub right now.

**What it is:** multi-panel terminal app for running Claude Code (and Codex, and any other shell-driven AI agent) side by side in one window. Built it on top of the same multi-terminal component that runs in my Lyfe app.

**What's interesting about it:** prompt packs. A `.deck.json` file describes a multi-panel terminal layout — panels, tabs, cwd, start commands, env hints. Click `📚 packs` in the app, pick one, your panels reconfigure in 2 seconds. 5 packs ship with the app:
- `claude-code-basic` — single Claude Code session
- `dual-claude-pair` — code + plan side by side
- `trading-workflow` — Claude analysis + Python scratch + dated journal
- `pluto-personal-strategist` — my actual setup, cross-machine via `${USERPROFILE}` + `${VAULT}`
- `example` — schema reference

Plus `💾 export` — save your current setup as a pack to share. `🔌 MCPs` — curated MCP install commands (filesystem, GitHub, Puppeteer, Brave Search, Fetch, Memory). `⚡ agent grid` — one-click 4-up Researcher/Coder/Reviewer/Journal layout. `⚙️ settings` — Anthropic key + `${VAULT}` path + factory reset. Auto-update banner. System tray + hide-on-close (sessions keep running). Pluto Dark / Pluto Light themes.

**Download:** https://github.com/plutothedev/plutos-terminals/releases/latest

Windows MSI or standalone `.exe` (no install). Mac/Linux + signed installers coming later — those need hardware + cert money I don't want to spend before knowing if anyone wants this.

**Build a pack, drop it in `#packs` (or wherever).** I'll merge the good ones into the next release.
