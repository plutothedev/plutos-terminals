Three targeted fixes on top of v0.1.11's whole-app theming.

## What changed

### 🎨 Modals now follow the active skin

Settings modal, confirm dialogs, toasts, MCP installer, setup checker, URL pack import, project dialog, update banner — all now read the active skin's CSS variables instead of hardcoded dark colors. Pick **Daylight** from ⚙️ → APP SKIN and the entire modal flow flips to a light palette: white modal background, dark text, light gray borders. Pick **Synthwave Sunset** and modals get the deep-purple surface.

Implementation:
- `applyGlobalSkin(skinId)` helper sets `data-phn-skin` on `<html>` so portaled / sibling elements (toasts, modals via Provider tree, update banner) inherit skin CSS vars. Previously the data-attr was only on TerminalsTab's outermost div, which doesn't propagate to the toast container that lives as a sibling in the React tree.
- `Modal.jsx` refactored: backdrop, modal box, header, title, close button, body all use `.phn-modal-*` classes. New CSS rules in `headerSkins.js` consume skin vars: `.phn-modal-overlay`, `.phn-modal`, `.phn-modal-header`, `.phn-modal-title`, `.phn-modal-close`, `.phn-modal-body`. Body inputs/selects/textareas auto-styled.
- `MODAL_COLORS` export refactored to use `var(--phn-...)` references — all components that destructured `{ FG, FG_ACTIVE, BORDER, ACCENT, M }` now automatically inherit the skin without per-component changes.
- `Toast.jsx` toast container background uses `var(--phn-surface-bg)` so toasts feel native to the active skin.
- `ProjectDialog.jsx`, `ProjectSidebar.jsx`, `SettingsModal.jsx`, `McpInstaller.jsx`, `PackUrlModal.jsx`, `SetupChecker.jsx`, `UpdateBanner.jsx` — hardcoded `#0a0a0a` / `#181818` values inside style objects swapped for `var(--phn-page-bg)` / `var(--phn-surface-bg)` references.

### 🔮 Glass skin actually blurs

The glass skin's `--phn-surface-bg: rgba(20,20,30,0.55)` only worked on the header (which had explicit `backdrop-filter`). Sidebar, status bar, and modals had `rgba` backgrounds without the blur, so they looked muddy instead of frosted-glass.

Fix: added a glass-specific rule to `headerSkins.js`:

```css
[data-phn-skin="glass"] .phn-statusbar,
[data-phn-skin="glass"] .phn-sidebar,
[data-phn-skin="glass"] .phn-sidebar-header,
[data-phn-skin="glass"] .phn-modal,
[data-phn-skin="glass"] .phn-toast {
  backdrop-filter: blur(24px) saturate(180%);
  -webkit-backdrop-filter: blur(24px) saturate(180%);
}
[data-phn-skin="glass"] .phn-modal-overlay {
  background: rgba(0,0,0,0.35);
  backdrop-filter: blur(8px);
}
```

Now picking Glass gives the full frosted-glass effect across every surface — header, sidebar, status bar, modals, modal backdrop. The colorful page-bg radial gradients show through.
