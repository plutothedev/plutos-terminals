# v0.1.4 — proper toggle UX

## What was wrong with v0.1.3

The `💻 TERMINAL ↔ 🤖 AGENT` view toggle was a single text-flipping button, and it lived INSIDE the terminal-view wrapper — which has `visibility: hidden` when in agent mode. So once you switched to agent view, the toggle disappeared. Only way back to terminal was clicking a card. Real bug.

Plus the single-button-with-flipping-text isn't actually a toggle UI — it's just a button that's hard to read at a glance.

## Fix

- **Segmented control** showing both halves side-by-side — `[💻 TERMINAL][🤖 AGENT]`. The current view is highlighted (filled background, dark text); the other is muted. Click the muted half to switch.
- **Toggle in BOTH headers** — terminal-view header AND agent-view header. Always visible regardless of which view you're in. Click from either side to flip.

## What's in this release

- **`plutos-terminals_0.1.4_x64.msi`** — Windows installer
- **`plutos-terminals.exe`** — standalone binary, run-without-install

All v0.1.3 features intact (which carried v0.1.2 features which carried v0.1.1 features…). Pure UX fix on the view toggle.
