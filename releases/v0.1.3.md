# v0.1.3 — hotfix for v0.1.2 blank-screen crash

## What broke

v0.1.2 introduced a temporal-dead-zone `ReferenceError` at `TerminalsTab` mount: two new `useCallback` declarations near the top of the component referenced `persist` in their dep arrays, but `persist` was declared further down in the same function. React caught the throw and rendered nothing → users saw a blank black window after install/launch.

## What's fixed

- Removed the dead `setViewMode` callback (the toggle button uses `save()` inline; `setViewMode` was never wired).
- Rewrote `onFocusTabInTerminalView` to do its full state mutation in a single `save()` call instead of calling `persist` (which wasn't yet defined at that point in the function body).
- Added a code comment near the top of the component flagging the `persist`-declared-later trap so the fix doesn't get accidentally undone.

## Action for v0.1.2 users

Upgrade to v0.1.3. The auto-update banner will surface the new version on next launch; or download the MSI/exe directly from below.

If you installed v0.1.2 via MSI: uninstall v0.1.2 (Settings → Apps → Pluto's Terminals → Uninstall), then install v0.1.3.

## What's in this release

- **`plutos-terminals_0.1.3_x64.msi`** — Windows installer
- **`plutos-terminals.exe`** — standalone binary, run-without-install

All v0.1.2 features intact (agent view toggle, branded toasts/confirms, status bar, setup checker, etc.) — this is purely a crash-fix.
