# v0.0.3 — bundled packs + cross-machine paths

Pack ergonomics pass. v0.0.2 had pack loading via file picker only and packs with hardcoded paths broke on other machines. v0.0.3 ships every pack inside the binary and adds env-var expansion in cwd so packs work cross-machine.

## What's new

- **📚 packs dropdown** in the header — pick from any of the 5 bundled packs (`claude-code-basic`, `dual-claude-pair`, `trading-workflow`, `pluto-personal-strategist`, `example`) and load with one click. No file picker needed.
- **Drag-and-drop pack files** onto the app window — alternative load path for custom packs you didn't bundle.
- **`📁 from file` button** (renamed from `📦 load pack`) for clarity on the file-picker path.
- **Templated `cwd` paths in packs** — `${USERPROFILE}`, `${HOME}`, `${VAULT}`, or any process-env variable expand at spawn time. Packs now ship cross-machine without manual editing.
- **`pluto-personal-strategist` rebuilt as cross-machine template** — uses `${USERPROFILE}` for home + `${VAULT}` for vault path. Set `VAULT` env var on your machine and the pack works.
- **Empty-pane Quick tips** — replaced stale "sync in header scrolls all panes" tip with "load a .deck.json prompt pack from the header" pointing at the new dropdown.
- **`prompt-packs/README.md` catalog** — every pack documented by purpose, layout, agent, requirements, and gotchas. Browse on GitHub or in your local clone.

## What's in this release

- **`plutos-terminals_0.0.3_x64.msi`** — Windows installer
- **`plutos-terminals.exe`** — standalone binary, run-without-install

## Install (Windows)

Download the MSI → double-click → Windows Installer walks you through. Or download the `.exe` and run directly.
