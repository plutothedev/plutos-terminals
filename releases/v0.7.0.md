## Pluto's Terminal v0.7.0

Every finding from the August full-codebase audit, closed, plus the keyboard
and Light-theme work that came out of it. Full detail in `CHANGELOG.md`.

### New
- Switch tabs from the keyboard: Ctrl+Tab / Ctrl+Shift+Tab cycle, Alt+1..9
  jump by position. Remappable. (Alt+digit does not fire on macOS; use
  Ctrl+Tab there.)
- The whole window is keyboard-complete: tab strip, tab menu, the collapsed
  side rails, dialogs and form fields, with a focus ring that follows your skin.
- Light theme done right: every colour token declared in all 14 skins, Light
  contrast failures down from 27 to 4, dark skins unchanged.

### Fixed
- Detach to new window no longer loses the session.
- Scrollback cleanup can no longer delete an open tab's history.
- SSH host-key pinning no longer rewrites your `~/.ssh/known_hosts`, and
  Windows usernames with accented characters connect again.
- SFTP uploads keep the file's permissions (a 0600 key stays 0600).
- Workspace recovery handles a missing backup, not only a corrupt one, and can
  no longer race a factory reset.
- "Later" on an update no longer hides a newer security patch for a day.
- Ask AI, macros, recording and broadcast act on the pane you are in.
- The AI cost readout no longer charges every model at the Opus rate.

### Under the hood
- The release pipeline refuses a tag whose version does not match the source,
  refuses to publish unsigned, and never publishes from a manual run. Actions
  are pinned to commit SHAs. Static analysis runs in CI.
- Dependency advisories cleared (js-yaml, cryptoki, rustls).

**Updating:** if you run v0.6.1 the app offers this release on launch and
installs it in place. Older versions have no updater and need one manual
install; verify the download against `SHA256SUMS` first.
