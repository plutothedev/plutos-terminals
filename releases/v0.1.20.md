# v0.1.20 — bracket buttons locked + README rewrite

Two cleanups, no new features.

## What changed

### Header buttons locked to bracket style

The HEADER BUTTONS picker (6 options) added in v0.1.13 is gone. All buttons now render in **bracket** style — `[ label ]` terminal aesthetic, no borders — across every skin and density.

**Why:** the picker was a brainstorm fork that got shipped without the "does this earn its complexity?" check. Six button styles is six entry points to choose from for a stylistic decision that 95% of users won't tune. Locking to bracket commits to a single coherent aesthetic and reduces the settings surface.

**What this means:**
- ⚙️ settings no longer shows the HEADER BUTTONS dropdown
- App.jsx hardcodes `applyGlobalButtonStyle("bracket")` regardless of saved `st.headerButtonStyle`
- Skin picker (10 options) and density picker (3 options) remain — those are user-meaningful axes
- Existing users who picked `pill` / `ghost` / `filled` / `chip` / `default` lose that pref; their app now shows brackets like everyone else

`HEADER_BUTTON_STYLES` array + per-style CSS rules remain in `headerSkins.js` for reference; future versions could re-introduce a curated subset if pluto changes mind.

### README rewrite

The repo README was written across v0.1.2 → v0.1.12 → v0.1.13 with each rev appending. v0.1.20's rewrite reflects current state:

- **Status header** updated to v0.1.20 + accurate feature list
- **Quick start** section added (5 steps from download to working session)
- **Features** restructured into 5 groups: Agents+workflow / Visual customization / Power UX / Onboarding+setup / MCP+extensions / App-level polish
- **Prompt packs** mentions all 11 by name (was: 4 packs in old README)
- **Roadmap** lists shipped vs. coming (v0 / v0.1 / v0.2 / distribution blockers)
- Removed: agent-toggle / agent-grid references (gone v0.1.7), Pluto Dark/Light terminal-theme picker references (gone v0.1.11), Discord URL settings field (gone v0.1.10), 4-pack count (now 11), button-style picker (gone in this release)
