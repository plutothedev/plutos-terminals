# v0.1.19 — bundle 6: multi-window via Tauri WindowBuilder

🪟 **Open multiple independent app windows** — different layouts, different skins, different agents, all running side by side.

## What's new

### Multi-window support

`Ctrl+K` → **🪟 Open new window** spawns a fresh window with its own independent state. Each window has:
- Its own panel layout
- Its own skin / button style / density / pure-black-terminal toggle
- Its own recent packs list
- Its own projects sidebar
- Shared API key (saved in the default window applies to all windows)

The new window's title shows `Pluto's Terminals — <id>` (id is a 6-char timestamp suffix). State is namespaced per window in localStorage: `plutos-terminals:state:v0:<window-id>`.

### Implementation

**Rust side (`src-tauri/src/commands.rs`):**
- New `spawn_new_window(window_id)` Tauri command
- Sanitizes the window-id (alphanumeric + `-` `_`, max 32 chars)
- If a window with that label already exists, it's focused (no duplicate spawn)
- Otherwise: creates a new `WebviewWindow` via `WebviewWindowBuilder` pointing at `index.html?w=<id>`, 1280×820 default size, 900×600 min, resizable, decorations on
- Returns the window's label for the caller to confirm

**Frontend (`src/App.jsx`):**
- New `getWindowStorageKey()` reads `?w=` from `window.location.search`
- Default window (no query param) keeps the original storage key for backward-compat
- Secondary windows get `:<id>` suffix → independent state
- `WINDOW_ID` exported for components that want to display it

**Use cases:**
- One window for trading workflow (Pluto Style skin, trading-workflow pack)
- Another window for code work (Linear skin, codebase-explorer pack)
- A third for content writing (Sunset skin, content-script-writer pack)

All running concurrently, each with its own PTYs and Claude sessions.

### Limitations

- **Independent state means independent keyboard shortcuts** — Ctrl+K in window A only affects window A. There's no cross-window command.
- **No window-list overview** — to switch between windows, use Alt+Tab (Windows) or click the taskbar icon for the window you want.
- **Closing a window hides it** (system-tray pattern from v0.0.x carries over). Tray "Quit" still kills all windows + every PTY across all windows.
- **State sharing is opt-in:** by default each window has its own state. If you want two windows on the same layout, you'd need to copy state manually (or just open the same pack in both).
