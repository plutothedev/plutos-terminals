## Pluto's Terminal v0.7.3

SSH and serial tabs fold into splits, and your API keys stay with the provider you picked. Full detail in `CHANGELOG.md`.

### New
- **Drag an SSH or serial tab into a split.** Dropping a tab on the edge of
  another tab's pane used to work only for local terminals. An SSH or serial
  session now folds in the same way and keeps running, and after a restart the
  pane comes back as itself (same host or port, folder and start commands). A
  password login asks for its password again after a restart, as an SSH tab
  always has.
- **Detaching a tab to a new window keeps all of its panes,** each one
  re-opened as itself. Detach used to keep only the first.

### Safer
- **Claude-compatible gateways no longer receive your Anthropic key.** Since
  v0.2.0, with Moonshot (Kimi), Z.AI (GLM) or MiniMax picked in Models, new
  shells carried your Anthropic key next to the gateway's own token, and Claude
  Code sends both once it uses that key (always in print mode; in an
  interactive session after you approve it at its one-time prompt). Those
  shells now get only the gateway's token. A key your own shell startup file
  exports still goes along, so take it out of that file if you use one of
  these gateways. If you picked one of them while an Anthropic key was saved,
  rotating that key is a sensible precaution.
- **The app's AI calls no longer follow a redirect to another host or port, or
  from https down to plain http.** MCP server tokens get the same rule, and are
  never sent to a plain-http address outside your own machine or local network.
- **A saved model choice that cannot be used here is no longer swapped for
  another provider.** If it names a provider this device has no key or address
  for (the choice syncs between devices; keys do not), new shells and the AI
  get no model and the app says why, instead of quietly using your default
  Claude key.
- **Model ids and provider addresses are checked** before they reach a new
  shell, so a stray control character or an oversized value cannot stop shells
  from starting.

### Fixed
- **Shells restored at launch wait briefly for your API keys** from the
  keychain, and start at their pane's real size.
- **A setting saved while the app first reads your keys** is no longer undone,
  and can no longer delete a saved key the app had not shown you yet.
- **Every pane is labelled with the machine it runs on**, in the broadcast
  picker, the file dock, port forwarding, the network tools and on your phone.
- **The live cost estimate prices the model you are running.** It had read
  Opus 5.5 at about 3.7 times its real cost, and had no price for Fable.

### Changed
- DOMPurify, which the code editor uses, is 3.4.16, clearing a low-severity
  advisory.
