## Pluto's Terminal v0.4.2 — OLED Black theme

### New
- **OLED Black** — a third appearance option next to Dark and Light
  (Settings → Appearance). Every surface — menu bar, toolbar, sidebar, tab
  strip, status bar, *and* the terminal — is true `#000000`. Structure comes
  from hairline borders instead of grey panels, so on an OLED display the
  background pixels are literally off. Also selectable in the OS light/dark
  sync slots.

### Downloads
- **`Plutos-Terminal_0.4.2_x64_en-US.msi`** — recommended Windows installer.
- **`Plutos-Terminal_0.4.2_x64-portable.exe`** — portable single-exe, no install
  (needs the WebView2 runtime, which Windows 11 ships).
- macOS `.dmg` / Linux `.AppImage`+`.deb` attach automatically when the CI build
  for the tag completes.

Builds are unsigned → SmartScreen may warn: **More info → Run anyway**. The MSI
upgrades a prior install cleanly.
