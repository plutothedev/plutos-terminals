## Pluto's Terminal v0.4.3 — OLED Black is the default

### Changed
- **OLED Black is now the default look.** Fresh installs boot straight into
  true-#000 everything; existing installs on the old default dark are switched
  over once automatically. If you prefer the previous grey-dark or light
  chrome, they're one click away in **Settings → Appearance** — an explicit
  choice (Dark, Light, or a custom theme) is never overridden.
- The menu-bar sun/moon toggle now flips between **OLED ⇄ Light**.

### Downloads
- **`Plutos-Terminal_0.4.3_x64_en-US.msi`** — recommended Windows installer.
- **`Plutos-Terminal_0.4.3_x64-portable.exe`** — portable single-exe, no install
  (needs the WebView2 runtime, which Windows 11 ships).
- macOS `.dmg` / Linux `.AppImage`+`.deb` attach automatically when the CI build
  for the tag completes.

Builds are unsigned → SmartScreen may warn: **More info → Run anyway**. The MSI
upgrades a prior install cleanly.
