# v0.1.5 — iOS-style toggle switch

v0.1.4's segmented-control toggle still didn't read as a toggle to users. v0.1.5 ships an iOS-style toggle switch — pill track with sliding knob — that's instantly recognizable as a flip-between-two-states control.

## What's different

**Before (v0.1.4 segmented control):**
```
[💻 TERMINAL][🤖 AGENT]
```
Two adjacent buttons with one filled. Subtle.

**Now (v0.1.5 iOS toggle):**
```
💻 TERMINAL  [⚪━━]  🤖 AGENT       (terminal active — knob left, blue glow)
💻 TERMINAL  [━━⚪]  🤖 AGENT       (agent active — knob right, magenta glow)
```

- Pill track between the two labels
- Knob slides left ↔ right as you click
- Knob glows blue (#4DAAFC) in terminal mode, Pluto-magenta (#FF0080) in agent mode
- Active label is bold + bright; inactive is dim
- 180ms ease-out animation on the slide
- Click anywhere on the whole control to flip

Mirrored in both terminal-view and agent-view headers so it's always visible.

## What's in this release

- **`plutos-terminals_0.1.5_x64.msi`** — Windows installer
- **`plutos-terminals.exe`** — standalone binary, run-without-install

All v0.1.4 features intact. Pure UX upgrade on the view toggle.
