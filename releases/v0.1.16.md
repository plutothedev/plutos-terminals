# v0.1.16 — bundle 3: keyboard shortcuts + Cmd+K palette + onboarding tour

Power-user features. Three additions.

## What's new

### ⌨ Keyboard shortcuts

Window-level capture so they fire even when xterm has focus. Uses `Ctrl+Shift+` for tab/window operations to avoid colliding with shell readline bindings.

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Command palette |
| `Ctrl+P` | Find a pack |
| `Ctrl+,` | Open settings |
| `Ctrl+Shift+T` | New tab in active panel |
| `Ctrl+Shift+W` | Close active tab |
| `Ctrl+1` … `Ctrl+8` | Switch to panel N |

Implementation: `useEffect` registers a `keydown` listener at window-capture phase, checks modifier + key combos against a refs-keyed callback map, calls `preventDefault` + `stopPropagation` on handled keys so they don't leak to xterm.

### 🎯 Cmd+K command palette

Press `Ctrl+K` to open. Searchable list of all top-level actions (pack search, MCPs, setup, settings, new tab, add panel, switch panel N, export pack, …) with arrow-key navigation, Enter to execute, Esc to close.

Each command shows: icon · label · hint · keyboard shortcut (if any). Filters by label / hint / shortcut substring.

Component: `src/components/CommandPalette.jsx`. Uses Modal.jsx wrapper so it inherits skin styling automatically.

The palette is the unified entry point: instead of remembering which button does what, type what you want and hit Enter.

### 🎓 4-step onboarding tour

`OnboardingOverlay.jsx` rewritten from a single welcome card into a proper 4-step walk-through that fires on first launch (after the welcome screen):

1. **Terminals + Projects** — multi-panel grid, project sidebar, activity dots
2. **Skins paint the whole app** — 10 skins, 6 button styles, 3 densities, where to find them
3. **Prompt packs** — what `.deck.json` packs are, the 11 shipped, systemPrompt auto-write
4. **Power features** — keyboard shortcut reference card, command palette, setup checker pointer

Skin-aware (uses CSS vars throughout — looks right under any skin). Step indicator at top. Skip / Back / Next buttons. `autoFocus` on Next. Esc dismisses.

Existing users who already dismissed the v1 onboarding (`st.terminalsOnboarded === true`) won't see it again. Fresh installs get the full tour.
