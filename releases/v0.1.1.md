# v0.1.1 — plug-and-play pass

The honest plug-and-play surface. v0.1.0 shipped feature-complete v1 but assumed users had the dev toolchain (Node.js, Claude Code CLI, Anthropic API key) already installed. v0.1.1 adds detection + guidance so a fresh download can verify their setup before typing `claude` and hitting "command not recognized."

## What's new in v0.1.1

- **🚀 Setup modal** — header button that detects Node.js, npm, Claude Code CLI, and your saved Anthropic API key. Shows a checklist with status icons + per-item install hints + copy-command buttons for anything missing.
- **First-launch auto-detect** — if `claude` isn't on your PATH on first run, the setup modal auto-opens so you don't type into a blank terminal and bounce.
- **Live API test** in the setup modal — clicks a button, calls the Anthropic Messages API with your saved key + a 1-token throwaway request, reports OK or fail. No need to install Claude CLI to verify your key works.
- **Welcome screen prereq note** — magenta callout about Node.js + Claude CLI requirement so users know upfront.
- **`prompt-packs/HOW_TO_USE.md`** opens with the setup-check section.
- **README "Prerequisites"** section before features — no more "wait, why isn't claude working" surprise.
- **`check_command_version` Tauri command** — backend support for the setup modal's binary detection. Reports the version string of any allowlisted-name binary (rejects paths/dots/spaces in name as a basic guard).

## What's in this release

- **`plutos-terminals_0.1.1_x64.msi`** — Windows installer
- **`plutos-terminals.exe`** — standalone binary, run-without-install

## Install (Windows)

Download → double-click → SmartScreen warning ("More info" → "Run anyway") → app launches → first-run setup check fires automatically.

## Install Claude Code (if the setup check flags it missing)

1. Install Node.js LTS from [nodejs.org](https://nodejs.org/)
2. Restart Pluto's Terminals (so the new PATH is picked up)
3. In any terminal pane, run: `npm install -g @anthropic-ai/claude-code`
4. Get an Anthropic API key from [console.anthropic.com](https://console.anthropic.com/) → paste into ⚙️ settings
5. Re-run setup check — should be all ✓
