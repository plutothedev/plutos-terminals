## Pluto's Terminal v0.4.1 — Clean terminal boot

### Fixed
- **No more wall of code when a terminal opens.** The shell-integration setup
  (themed prompt, command blocks, autosuggest config) used to echo visibly for
  a second or two before the welcome box cleared it. The terminal stream is now
  held back until setup finishes, so a new pane goes straight to the welcome
  box — and a restored pane goes straight to its replayed scrollback. The setup
  noise also no longer pollutes saved scrollback or session transcripts.
  A 4-second failsafe flushes everything if an unusual shell never completes
  setup, so a pane can never come up blank.

### Downloads
- **`Plutos-Terminal_0.4.1_x64_en-US.msi`** — recommended Windows installer.
- **`Plutos-Terminal_0.4.1_x64-portable.exe`** — portable single-exe, no install
  (needs the WebView2 runtime, which Windows 11 ships).
- macOS `.dmg` / Linux `.AppImage`+`.deb` attach automatically when the CI build
  for the tag completes.

Builds are unsigned → SmartScreen may warn: **More info → Run anyway**. The MSI
upgrades a prior install cleanly.
