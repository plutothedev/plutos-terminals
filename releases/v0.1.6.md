# v0.1.6 — toggle is the agent grid (corrected interpretation)

I built the wrong "agent" view. v0.1.5's toggle flipped between terminal mode and a cards-grid monitoring view. Pluto's actual ask: the toggle should switch between **regular terminal mode** and the **4-up Claude Agent Grid** (Researcher / Coder / Reviewer / Journal panels each running `claude`). v0.1.6 fixes that.

## What changed

- **Removed the standalone `⚡ agent grid` header button.** The toggle does it now.
- **Toggle now controls panel layout, not a separate render mode.** Click `🤖 AGENT GRID`:
  - Confirms first ("replaces current panels — current layout will be saved and restored when you switch back")
  - Stashes your current panels in `st.previousPanels`
  - Replaces panels with the 4-up Claude grid (Researcher / Coder / Reviewer / Journal, each with `claude` as the start command — boots straight into Claude Code if your CLI + key are set up)
- Click `💻 TERMINAL`:
  - Restores your previous panels from the stash
  - Falls back to default 1-panel layout if no stash exists
- **Removed the cards-grid monitoring view (AgentView component).** Not what was asked for; can be re-added as a separate "Monitor" feature later if useful.
- **Knob labels updated** to `💻 TERMINAL` ↔ `🤖 AGENT GRID` to make the binary explicit.

## How to use

- Default state: terminal mode. Use the multi-panel grid however you want (custom layouts, projects, packs, etc.).
- Need to spawn 4 parallel Claude agents fast? Click `🤖 AGENT GRID` on the toggle. App confirms, stashes your layout, drops you into the 4-up grid with `claude` running in each.
- Done with parallel work? Click `💻 TERMINAL` on the toggle. Your stashed layout comes back exactly as you left it.

Tabs you ADD or MODIFY while inside agent-grid mode persist within agent-grid mode but don't affect your stashed terminal-mode layout.
