## Pluto's Terminal v0.7.6

Security updates, safer MCP servers, and a long list of dialog, focus and keyboard fixes. Full detail in `CHANGELOG.md`.

### Safer
- **MCP servers over HTTP can no longer exhaust the app's memory.** A reply is
  capped at 16 MiB (one JSON reply or one streamed event) and an error body at
  64 KiB (RUSTSEC-2026-0462, fixed by moving the MCP library from rmcp 1.7 to
  3.11).
- **A misbehaving MCP server cannot hang the app's tools.** Connecting times
  out after 30 seconds, listing tools after 60, and a tool call after 10
  minutes. A tool list is capped at 50 pages, 5,000 tools and 8 MiB of tool
  text. A server that timed out or exited is dropped and reconnected on next
  use, with its tools read again.
- **Stopping an MCP server stops all of it.** A server started through
  `cmd /c` or `uvx` used to leave the real server process running after a
  timeout; the whole process tree now goes with it.
- **The auto-updater moves to tauri-plugin-updater 2.14.1 and Tauri 2.12.7**,
  clearing the zip advisories (RUSTSEC-2026-0367, -0368, -0369, -0429, -0545,
  -0548). libz-sys 1.1.33 and quinn-udp 0.5.16 clear RUSTSEC-2026-0544 and
  -0538.
- **SSH key generation on macOS and Linux** writes its passphrase helper into
  a fresh private folder instead of a guessable path in the shared temp
  folder.

### Fixed
- **The remote file editor no longer overwrites a file with nothing.**
  Ctrl+S while a file was still loading, or after it failed to load, saved an
  empty file over the remote one. Closing while a save is in flight now waits
  for it, and keeps the editor open if the save fails.
- **A recovered recording can no longer be discarded without asking.** A
  second confirmation (for example from a keyboard shortcut) that arrived
  during the recovery prompt could answer it as "discard". Confirmations now
  wait their turn, and none is answered for you.
- **Passwords stay with the session they were typed for.** Two saved RDP
  sessions on the same host and port, or two SSH prompts for the same user and
  host, no longer share a typed password.
- **Saving an edit to a session that was removed elsewhere** (sync, another
  window) saves it as a new session instead of silently dropping it.
- **Explain error no longer offers "Run fix" with the previous error's
  command** after the model is removed, and Summarize no longer shows the
  previous summary's paste target.
- **Dialogs give focus back to whatever opened them**, a destructive
  confirmation opens with Cancel selected, and back-to-back confirmations each
  start fresh.
- **Dragging a text selection out of a dialog no longer closes it.**
- **Clicking zoom on a pane puts the keyboard in that pane.**
- **A project's "finished" shake no longer gets stuck** when other projects
  finish at the same time.
- **The pairing dialog for the phone closes with Escape**, including right
  after starting or stopping the server.
- A notification you have focused stays until you leave it.

### Accessibility
- Session rows, folders, file browsers, history search, toasts, pane controls
  and dialogs work from the keyboard (Enter, Space, Escape, Tab stays inside
  dialogs), with no change to how they look.

### Under the hood
- Every static check now gates the build: eslint (230 errors and 55 warnings
  to none), knip (dead code removed), clippy on Windows and macOS, and
  semgrep, alongside the existing license and dependency audits.
