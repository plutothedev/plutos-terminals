# v0.1.26 — pack catalog curated (26 → 22) + agentic-feature-ship killer pack + 4 new B-roll graphics

Curation pass before launch. v0.1.25 ballooned the catalog to 26; v0.1.26 cuts 5 weak ones and adds 1 headline pack that earns the demo slot.

## What changed

### 🚀 New headline pack: `agentic-feature-ship`

Four-pane developer flagship — Explorer (read first, recommend second) + Plan (options + tradeoffs, no code) + Code (implement, no re-litigation) + Debug (root-cause chaser, idle until tests fail). Each pane has a distinct systemPrompt locking the role. The full "shipping a feature" workflow as a single `.deck.json` file.

This is the pack you load on stage. Other packs supplement; this one demonstrates the whole thesis.

### 🪓 Cut 5 weak packs (catalog 26 → 22)

| Pack | Why cut |
|---|---|
| `prd-writer` | Very PM-niche; most viewers won't use it; shape duplicates other coaching packs |
| `landing-page-writer` | Founder-niche; the actual draft work overlaps with `writing-helper` |
| `ai-tool-comparison` | Single-pane, single-question — doesn't justify a pack vs. a one-shot Claude prompt |
| `standup-prep` | Dev-only; structure (3 questions then format) duplicates `journal-buddy` |
| `weekly-retro` | Pattern-noticed angle is good but overlaps `journal-buddy`; can be re-introduced if there's demand |

Each pack now has a clear distinct reason to exist. No two packs do the same thing in slightly different words.

### 📐 4 new graphic sections in `design/video-graphics/index.html`

For B-roll cuts during the YouTube video:

1. **Agent anatomy** — what's INSIDE a Claude agent (4-step layered diagram showing the spawn → boot → systemPrompt arrival → in-role-response sequence). Educational; addresses "but how does it actually work?"
2. **Pack file anatomy** — annotated `.deck.json` code with callouts for each field (panels / cwd / startCommands / systemPrompt). Educational; demystifies the file format.
3. **vs alternatives** — comparison table across claude.ai chat, Cursor / Cline, Claude Code + tmux, and Pluto's Terminals. 8 capabilities × 4 tools. Positioning shot.
4. **Shareability flow** — 3-step visual: build a layout → export to file → share anywhere. Punchline on the unique primitive.

Plus updated nav + structure to flow logically.

### 📚 New research doc: `design/video-graphics/HOW-OTHERS-VISUALIZE-AGENTS.md`

Findings from researching how other AI YouTubers (Indy Dev Dan, Cole Medin, Matthew Berman, AI Jason, Mervin Praison) demonstrate agentic workflows. Concrete techniques + which apply / don't apply to Pluto's Terminals' UX. Source list at the bottom.

Key insight from research: **the visual paradigm for parallel agents is settled** — yellow/green status indicators, grid layouts, side-by-side panels. Most others use tmux which Windows users can't easily run. Pluto's Terminals fills the Windows-without-tmux gap with a polished native UI.
