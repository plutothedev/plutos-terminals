## Pluto's Terminal v0.7.7

Terminal history that comes back after a restart now stays back, however many times the app is restarted. Full detail in `CHANGELOG.md`.

### Fixed
- **A tab's history survives every restart, not only the last one.** The app
  saves each terminal's output and replays it when the tab is restored. Every
  shell session starts by clearing the screen, and replayed one after another
  each session's clear erased the last screen of the session before it (all of
  a short session). v0.7.6 kept the newest screen only. Now each saved session
  is marked, and the replay moves what is on screen into the scrollback at
  every mark, so nothing is on screen for a clear to erase.
- **Work in a tab you then leave idle is not pushed out by restarts.** Each
  restart adds about 4 KB of startup output to a tab's saved file that is
  never shown, and the replay counted it against its 256 KB limit. After about
  fifty restarts an idle tab's last real output stopped coming back although
  it was still saved. The limit now counts only what is shown.
- **A tab that was closed inside a pager or an editor (less, vim) comes back
  usable.** The new shell used to start inside the old program's full-screen
  mode. Mouse reporting, a cursor shape, colours, a scroll region or a
  hyperlink the old program left set no longer leak into the new shell
  either.
- **A slow-starting shell can no longer erase restored history**, including
  in a background tab that is opened while its shell is still starting.
- **Tabs with start commands** (agent tabs) keep the last screen of their
  history; the new process used to paint over it.
- The grey "scrollback restored" line always sits under the history, never on
  top of it.

### What you will notice
- A restored tab opens on an empty screen with the new prompt at the top. Its
  history is one scroll up, ending in the grey "scrollback restored" line.
  Before, the old screen showed for a moment and then jumped.

### Limits
- History saved by v0.7.6 or earlier has no session marks, so inside that part
  the old loss still applies. Everything from the first v0.7.7 session on is
  kept.
- What a session cleared stays cleared: `Clear-Host`, `clear` and programs
  that wipe the scrollback also wipe the restored history above them, exactly
  as they did when they ran.
- A background tab is replayed before it has its real size, so output that was
  painted at fixed positions (prompts being redrawn, full-screen programs) can
  land with blank gaps. Unchanged from before.
- SSH and serial tabs, and the phone page, replay exactly as before.
