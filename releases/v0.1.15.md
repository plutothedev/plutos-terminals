# v0.1.15 — bundle 2: recent packs + layout density + pack search

Three additions, no removals.

## What's new

### 🕐 Recent packs history
Last 5 packs you loaded surface in a "🕐 RECENT" group at the top of the 📚 packs… dropdown. Tracks pack source (bundled / file / url / export) so you can re-load the same external pack from a previous session. Stores the full pack JSON in localStorage (~1-3KB each, max ~15KB total).

Implementation: `applyPack(pack, source)` now accepts a source label and prepends to `st.recentPacks` array (deduped by name, capped at 5). The packs dropdown renders an optgroup of recents above the optgroup of bundled packs.

### 📐 Header density picker
Third axis alongside skin (10) and button-style (6). New ⚙️ field "HEADER DENSITY (LIVE PREVIEW)" with three options:
- **Default** — current spacing
- **Compact** — smaller padding, tighter gap, smaller font (more controls fit in narrow windows)
- **Spacious** — larger padding/gap, easier touch targets

CSS rules scoped by `[data-phn-layout="<id>"]` on `<html>`. Combines with skin + button-style = **10 × 6 × 3 = 180 distinct header configurations**.

New helper `applyGlobalLayout(id)` mirrors `applyGlobalSkin` / `applyGlobalButtonStyle`. Applied from App.jsx so first-launch picks up saved density too.

### 🔍 Pack search modal
New "🔍 find" button in the header opens a searchable modal listing all packs (recents at top, bundled below). Search filters by pack name AND description (case-insensitive substring). Arrow keys navigate; Enter loads; Esc closes. Click any pack to load.

Useful when the catalog grows past ~10 packs (we're at 11 now); also future-proofs for community pack imports.

Component: `src/components/PackSearchModal.jsx` — uses Modal.jsx wrapper so it inherits skin styling automatically.
