# v0.1.10 — header skin picker + 3 new packs + cleanup

Headline: a **HEADER SKIN** picker in ⚙️ settings with **10 visual themes** that change instantly as you pick.

## What's new

### 🎨 10 header skins, user-pickable
Open ⚙️ settings → **Header Skin** dropdown. Picks apply live (no save needed):

1. **Default** — flat dark, cyan accent (the original)
2. **Neon Cyberpunk** — magenta + cyan glow, edgy
3. **Pluto Magenta** — brand color as primary accent
4. **Retro CRT** — phosphor green-on-black, all caps, dashed borders
5. **Modern Dark** — Linear/Vercel-style refined SaaS polish
6. **Brutalist Mono** — pure black/white, sharp corners, all caps
7. **Glassmorphic** — translucent backdrop-blur (macOS frosted glass)
8. **Synthwave Sunset** — purple→orange gradient, hot pink title with glow
9. **Solarized Amber** — Hercules-monitor vintage warm amber
10. **Daylight** — actual light theme for outdoor/bright environments

Skin selection persists in localStorage. First-launch defaults to Default.

### 📦 3 new generic prompt packs

- **codebase-explorer** — 2 panes: Claude tuned to read-first/recommend-second + an inspect shell. For mapping unfamiliar codebases.
- **writing-helper** — 1 pane: Claude tuned for drafting/editing/critique. The conversation is the deliverable; no file-edit bias, no filler hype.
- **debug-session** — 2 panes: Claude in root-cause-chaser mode (pushes back on symptom-patches) + a repro shell. For when something's broken.

Catalog now: 6 functional + 1 reference = **7 packs** (`claude-code-basic`, `dual-claude-pair`, `codebase-explorer`, `writing-helper`, `debug-session`, `trading-workflow`, `example`).

## Cleanup

- **⚙️ Settings — Discord URL field removed.** It was editable for no reason; the link is now hardcoded. One less field to think about.
- **`example.deck.json`** updated — removed reference to deleted `pluto-personal-strategist` pack, dropped stale "v1 will support templated paths" note (templated paths already work since v0.1.0), switched the comment field from `system_prompt_hint` to the real `systemPrompt` field.
- **Tooltip** on ⚙️ settings button no longer mentions VAULT path or Discord URL (both removed in earlier passes).
- **Dead `onQuickSpawnGrid` callback** removed (17 lines) — leftover from the v0.1.7 agent-grid removal.
- `prompt-packs/README.md` updated to catalog all 7 packs.

## Issues identified (not yet fixed, surfacing for next pass)

- **Pack failure when `claude` not on PATH** — setup checker catches it on first launch, but a user who skips setup and loads a pack gets garbage output. Mitigation candidate: pre-flight `Get-Command claude` in startCommands.
- **Welcome-screen API key has no inline validation** — invalid key saves successfully, fails silently later. Setup checker catches it but only if user opens it.
- **Drag-drop pack zone has no idle visual hint.**
