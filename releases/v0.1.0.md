# v0.1.0 — feature-complete v1 (Windows)

The full v1 software-feature surface. v0.0.1 → v0.0.2 → v0.0.3 → v0.1.0 across two days. Mac/Linux installers + code-signing remain — those are distribution work, not feature work.

## What's new in v0.1.0

- **`💾 export`** button in header — save your current panel layout as a `.deck.json` you can share, version, or reload after a factory reset.
- **`⚙️ settings`** modal — edit Anthropic API key, `${VAULT}` path, Pluto Discord URL, or factory-reset all local state. No more "edit `src/App.jsx` line 5" friction.
- **`🔌 MCPs`** modal — curated MCP server catalog (filesystem, GitHub, Puppeteer, Brave Search, Fetch, Memory) with per-MCP description, install command, copy button, docs link.
- **Auto-update banner** — on app start, the app checks GitHub for a newer release and shows a dismissible bottom-right banner with a download link if one's out.
- **`${VAULT}` env injection** — settings-saved `vaultPath` flows into both spawned-shell env AND `cwd` expansion via the new `expand_env_vars_with_extra` resolver in pty.rs. Packs like `pluto-personal-strategist` now work cross-machine without manual editing.
- **Real Pluto Discord invite** — welcome screen "JOIN PLUTO DISCORD" button now points at [discord.gg/3cZQVgKF](https://discord.gg/3cZQVgKF).
- **Polish:** updated README + `prompt-packs/HOW_TO_USE.md` covering all the v0.1.0 surfaces.

## What's in this release

- **`plutos-terminals_0.1.0_x64.msi`** — Windows installer (~3 MB)
- **`plutos-terminals.exe`** — standalone binary, run-without-install (~9 MB)

## Install (Windows)

Download the MSI → double-click → Windows Installer walks you through. Or download the `.exe` and run directly without installing.

> **SmartScreen warning:** still unsigned. Click "More info" → "Run anyway."

## Carried over from v0.0.3

- `📚 packs` dropdown — 5 bundled prompt packs ship with the app
- `📁 from file` — file-pick a `.deck.json` from disk

- `⚡ agent grid` — quick-spawn 4-up Researcher / Coder / Reviewer / Journal
- API key persistence + auto-injection into spawned shells
- Templated `${VARNAME}` cwd path expansion
- Pluto-branded app icon

## Still ahead (distribution, not features)
