# v0.0.2 — feature-complete v1 (Windows)

The promised v1 software-feature surface. Same-day successor to v0.0.1. Mac/Linux/code-signing become subsequent ship events; this release is the full feature set on Windows.

## What's new since v0.0.1

- **In-app pack loader** — click `📦 load pack` in the header, pick a `.deck.json`, your panels reconfigure in one click. No more manual matching from `HOW_TO_USE.md`. Drop a pack into the [`prompt-packs/`](https://github.com/plutothedev/plutos-terminals/tree/main/prompt-packs) folder and load it directly.
- **Quick-spawn agent grid** — `⚡ agent grid` button instantly spawns a 4-up grid with role-labeled panels: Researcher / Coder / Reviewer / Journal. Multi-agent workflow in one click.
- **API key persistence + auto-injection** — paste your Anthropic key once on the welcome screen; every new shell inherits `ANTHROPIC_API_KEY` automatically. `claude` just works in any tab without per-shell setup.
- **Discord invite button** — direct link to the Pluto community Discord on the welcome screen.

## What's in this release

- **`plutos-terminals_0.0.2_x64.msi`** — Windows installer (~3 MB)
- **`plutos-terminals.exe`** — standalone binary, run-without-install (~9 MB)

## Install (Windows)

Download the MSI → double-click → Windows Installer walks you through. Or download the `.exe` and run directly.

> **SmartScreen warning:** still unsigned. Click "More info" → "Run anyway." Code-signing cert is on the post-feature-complete list.

## Carried over from v0.0.1

- Multi-panel terminal grid (lifted from Lyfe)
- xterm.js 5.5 + portable-pty backend
- System tray + hide-on-close (sessions persist in background)
- Project sidebar with cwd + start commands + drag-drop into panels
- Pluto Dark / Pluto Light themes
- 4 practical prompt packs in repo (`claude-code-basic`, `dual-claude-pair`, `trading-workflow`, `pluto-mind-strategist`) + `example.deck.json` schema reference
- Pluto-branded app icon (terminal-window silhouette + magenta cursor signature)

## Still ahead (not features — distribution)

- macOS installer (needs a Mac to build — Tauri can't cross-compile from Windows)
- Linux installer (.deb / AppImage)
- Code-signed Windows + Mac installers (cert acquisition)
- MCP one-click installer (per-MCP install logic; multi-day work)
