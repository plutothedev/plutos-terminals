## Pluto's Terminal v0.6.1 (2026-08-16)

Written after the fact: this release shipped on 2026-08-16 without a notes
file. It is the first signed release and, in practice, the first public
release since v0.5.0 (the v0.6.0 release exists but is unsigned and its public
tag points at the wrong commit). Everything listed under v0.6.0 in
`CHANGELOG.md` is included.

### New
- Signed, in-place auto-updates. The app checks on launch, verifies the
  payload against a key built into the binary, installs and relaunches.
- A 25-stop guided tour (offered on first run, replayable from Help).
- Split panes the modern way: keyboard splits, hover controls on every pane,
  drag a tab onto a pane edge to split there, double-click a divider to reset.
- Right-click pastes into the shell, PuTTY-style.
- About dialog, readable error messages everywhere, the window remembers its
  size and position, no white flash at boot.

### Fixed
- Thirty findings from the 2026-08-14 audit, including: remote hosts can no
  longer inject commands into your history through terminal escape sequences,
  SFTP transfers no longer truncate the destination before streaming, the
  workspace layout has a durable backup with recovery, and a crash in one pane
  no longer takes every other session with it.
- Fresh Windows installs detected npm, npx and the Claude Code CLI correctly.
- The dead Discord invite was replaced everywhere.

### Under the hood
- Four performance streams: output coalescing on the PTY hot path, render
  containment so switching tabs stops re-rendering the app, streaming for
  every AI surface, and a bundle that dropped Monaco from 15.7 MB to 6.6 MB.
- Linux builds are cut from the release matrix until they can be tested.
